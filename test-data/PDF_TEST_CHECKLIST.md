# PDF পরীক্ষা পাতা (খ২)

PDF কোড (`src/utils/pdfGenerator.ts` ও সংশ্লিষ্ট) বদলালে প্রতিবার এই নমুনা দিয়ে PDF বানিয়ে দেখো।
এই ডেটা অ্যাপে ডিফল্ট থাকে না - দরকারে ইমপোর্ট করবে।

## নমুনা ডেটা ইমপোর্ট

1. `pdf-test-collection.json` ফোনে কপি করো।
2. অ্যাপে **Type CQ** ট্যাব -> ইমপোর্ট -> ফাইলটি বাছো -> **Merge** মোড (Replace নয়!)।
3. নতুন বিষয় আসবে: **[PDF পরীক্ষা] নমুনা** (১টি অধ্যায়, ১টি টাইপ, ৩টি উদ্দীপক, ১১টি প্রশ্ন, ৪টি ছবি)।
4. Create থেকে নতুন প্রশ্নপত্র বানাও, এই বিষয়ের সব প্রশ্ন বাছো।
5. পরীক্ষা শেষে বিষয়টি মুছে ফেললেই নমুনা চলে যাবে (বিষয়ের নাম `[PDF পরীক্ষা]` দিয়ে চেনা যায়)।

## কোন প্রশ্নে কী দেখবে

| প্রশ্ন | কী পরীক্ষা হয় |
|---|---|
| উদ্দীপক ১ (ক-ঘ) | ইনলাইন সূত্র লেখার সাথে একই লাইনে; ভগ্নাংশ `\frac`, বর্গমূল `\sqrt`, ঘাত |
| উদ্দীপক ২ (গ, ঘ) | দুটি ছবি: ১টি উদ্দীপকের উপরে, ১টি নিচে; বাংলা-ইংরেজি মিশ্র লেখা |
| গ (উদ্দীপক ২) | সমাধানের মাঝখানে ছবি |
| ঘ (উদ্দীপক ২) | সমাধানে `[[box]]` দিয়ে আলাদা লেখার বক্স + লম্বা (tall) ছবি |
| উদ্দীপক ৩ (গ, ঘ) | অনেক লম্বা উদ্দীপক - পাতার মাঝে কাটে কি না |
| গ, ঘ (উদ্দীপক ৩) | অনেক লম্বা সমাধান (১৮ ধাপ) - পাতার শেষে কিছু কাটে কি না |
| উদ্দীপকহীন খ | উত্তর ও সমাধান দুটোই নেই -> উত্তরমালা/সমাধান PDF-এ "দেওয়া নেই" |
| উদ্দীপকহীন গ | শুধু সংক্ষিপ্ত উত্তর আছে |
| উদ্দীপকহীন ঘ | শুধু সমাধান আছে |

## প্রতিবার যে PDF বানাবে

- শুধু প্রশ্ন
- প্রশ্ন + সংক্ষিপ্ত উত্তর
- প্রশ্ন + পূর্ণ সমাধান
- **ডার্ক থিমে** একবার (PDF সাদা-কালো থাকতে হবে, অ্যাপের রঙ ঢুকবে না)
