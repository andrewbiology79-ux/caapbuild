# Question Bank User Guide — Draft v1.70 (Not runtime verified)

## Main areas
- Create: access question creation and Paper Builder.
- Type_CQ: manage Subject → Chapter → Topic and Type_CQ questions.
- Chapter_CQ: manage Subject → Chapter and Chapter_CQ questions; no Topic layer.
- Filter: search across both scopes and combine scope/board/year/category/rating and Type_CQ question-type filters.
- Profile: presentation preferences, media library and Backup/Restore.

## Paper Builder
Choose a paper category, create a paper and sections, add source questions from either scope, adjust per-item overrides and marks, validate and export PDF. Paper snapshots preserve inserted text; images used by a paper are copied separately.

## Backup
Use manual `.qbbak` export to a location outside the app/phone where practical. Automatic backups are stored inside app-private storage and can be lost on uninstall/Clear data/device loss. Restore previews before confirmation and applies the staged swap after app restart. Keep a separate copy before any restore.

## Important limitation
This guide describes source-wired flows only. The current package was not built, tested or device-checked; screens, dialogs, permissions and output may differ. Do not treat this draft as final user documentation.
