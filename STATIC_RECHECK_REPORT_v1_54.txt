2. ADDITIONAL DEFECTS FOUND AND CORRECTED
A. Chapter_CQ rapid save tap race
- Added a synchronous guard before starting the save coroutine and disables save/dismiss actions while saving.

B. Chapter_CQ delayed draft writer race / stale draft resurrection
- Added an owner-keyed process-wide draft coordinator with a shared Mutex, revision generation, cancel-and-join, and a serialized final snapshot write.
- The same Room transaction now writes the optional stimulus, question, child rows, read-back checks and deletes the draft metadata key. A rollback retains the draft.

C. Type_CQ duplicate checker cancellation and stale state
- Rethrows CancellationException, verifies the active coroutine and job identity before changing warning/loading state.

D. Type_CQ post-commit read-back
- Moved insert/update group read-back checks inside DAO transactions and before draft deletion; removed repository-level post-commit result checks.

E. Mixed text/image solution positions
- Text-only replacement preserves non-TEXT solution part IDs and positions and appends any new text parts after existing positions. Image editing itself remains unimplemented.

F. Chapter_CQ nested transaction
- Replaced the inner public @Transaction call with a private shared DAO write body invoked by the outer transactional method. This removes reliance on nested @Transaction behavior.

G. Stale Chapter_CQ edit ID
- DAO distinguishes update-existing from insert-new and refuses an update if the row disappeared. The editor clears stale state and blocks Save if the selected question no longer exists.

H. Shared Chapter_CQ stimulus mutation
- When an edited stimulus is shared and content changes, DAO clones the stimulus and its existing image links and attaches only the edited question to the clone.

I. Primary Chapter_CQ board/year replacement
- When primary board/year changes, replace the old primary while preserving other secondary links; remove a secondary duplicate matching the new primary.

J. Cancellation and root navigation
- Chapter_CQ add/rename repository calls rethrow coroutine cancellation. Root Chapter_CQ screen no longer supplies a dead back arrow.
