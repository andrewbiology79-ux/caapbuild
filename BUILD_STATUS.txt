Question Bank Android build foundation — version 0.2.0

This ZIP is an initial implementation update to the Android/Room build harness, not a completed Question Bank application.

Database architecture: one physical QuestionBank.db file. Type_CQ, Chapter_CQ, and paper workflows remain logically separated by table families and repository boundaries.

Runtime database objects: Room registers the 35 ordinary application entities. The Room callback installs both FTS5 virtual tables, all 17 canonical triggers, and the idempotent system paper-category seed. The 10 FTS shadow tables are SQLite-managed and are not Room entities.

Canonical SQL inventory checks: 35 ordinary tables, 2 FTS5 virtual tables, 17 triggers, and 48 CHECK clauses.

Build evidence: no authoritative Android Gradle/Room KAPT compile result or device test was obtained while preparing this ZIP. Run the GitHub Actions workflow or `gradle --no-daemon :app:testDebugUnitTest` and retain the logs. Do not describe this package as build-verified until CI succeeds.
